# Race of the Day — free local prototype

Run `npm run dev` and open the printed address. In Creator’s Camp, choose **Host a race**, select an enabled passage and the built-in and/or custom racers to share, then **Open room**. Custom artwork comes from the host’s active player profile. One dino is one seat (up to 32). To try it on one computer, open the same address in a separate browser or private window, enter a nickname and choose **Join race**. Use the four-digit code, pick an available dino and wait for the teacher’s countdown. Use different tabs or windows for each role.

On a trusted classroom LAN, deliberately start a separate server on the teacher computer’s private IPv4 address, e.g. `node scripts/serve.mjs --classroom=192.168.1.25` (substitute the actual address). Everyone, **including the teacher**, must open the same printed LAN address. The default server listens on loopback only; no firewall settings are changed. A browser stores profiles per origin: use the existing game backup if you need to bring saved custom racers to the LAN address. Backup import requires a secure browser context, so for LAN testing it is easiest to add a racer directly in the workshop on that address. Do not expose this prototype to the public Internet.

Only the room’s passage, nicknames, selected thumbnails, progress, error counts and finish results are shared. Room data stays in memory, expires after two hours, and disappears on End room or server restart. A tab can reload and rejoin with its temporary role; removing a student frees the dino. Students type in Strict mode and clear misses with Backspace. The server ranks students by receipt of completion after its common start time; this is casual play, not a verified assessment. Classroom results do not overwrite solo progress or post to the online leaderboard.

Hosting and joining are free in this preview. Nothing counts unique users, charges a card, or enforces a future paywall. If the product later charges for hosting, make that a deliberate server-side teacher entitlement; keep student joining free. The static production game does not show room controls unless a same-origin classroom API is available. No online service or hosting subscription is needed to test locally.
